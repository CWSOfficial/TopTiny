# TopTini app source

- `screens/` contains navigation screens; every screen has its own `.styles.js` file.
- `components/` contains reusable JSX and matching style files.
- `context/` owns connectivity, city, venue, and profile app state.
- `navigation/` contains the native stack and bottom tab navigators.
- `assets/images/` and `assets/icons/` hold local media and brand assets.
- `styles/theme.js` is the shared visual token source.

All app source is JavaScript/JSX. No `.ts` or `.tsx` app modules are used.
