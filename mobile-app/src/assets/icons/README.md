# Flaticon icon assets

TopTini uses the official Flaticon UIcons regular-rounded font. The bundled TrueType font is in `uicons-regular-rounded.ttf`; `flaticonGlyphMap.js` maps app icon names to the official font code points.

Icons are used under the free Flaticon license and require attribution. The app includes an in-product attribution in the Profile screen: “Icons by Flaticon”.

Source: https://www.flaticon.com/uicons
Package: `@flaticon/flaticon-uicons`
