# TopTini image assets

- `toptini-logo-cream.png` and `toptini-logo-dark.png` are the supplied wordmarks used by the shared app header and auth screens.
- `toptini-app-icon.png` is the supplied brand icon used on the splash screen. Platform launcher icons are generated from the same source artwork.

The supplied brand folder did not include venue photography. Discovery cards continue to use the configured photo URLs and their existing fallbacks; replace those with client-approved venue photos when they are provided.
